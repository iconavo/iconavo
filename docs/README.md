# Iconavo — документация проекта

План, решения и пошаговые инструкции, по которым строится проект. Claude Code опирается на эти файлы в каждой сессии.

- [roadmap.md](roadmap.md) — план запуска: фазы, сроки, метрики, риски.
- [phase-0.md](phase-0.md) — подготовка к старту.
- [phase-1.md](phase-1.md) — данные и конвейер, с промптами для Claude Code.
- [phase-2.md](phase-2.md) — доставка: CDN, edge API, npm.
- [phase-3.md](phase-3.md) — пакет для разработчиков.
- [adr/](adr/README.md) — архитектурные решения: сводка, отдельный файл на каждое решение и продуктовые решения по фазам.

Имена: бренд Iconavo, организация на GitHub iconavo, scope в npm `@iconavo-ui`, веб-компонент `<iconavo-icon>`. Адреса вида `api.домен`, `cdn.домен` и `mcp.домен` — заглушки: вместо «домен» подставляется домен проекта.

Источник правды — документ «Roadmap запуска платформы иконок» в Claude. Эта папка — его выгрузка от 17 октября 2026; схемы из документа сюда не переносятся.

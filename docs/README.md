# Iconavo — документация проекта

План, решения и пошаговые инструкции, по которым строится проект. Claude Code опирается на эти файлы в каждой сессии.

- [roadmap.md](roadmap.md) — план запуска: фазы, сроки, метрики, риски.
- [phase-0.md](phase-0.md) — подготовка к старту.
- [phase-1.md](phase-1.md) — данные и конвейер, с промптами для Claude Code.
- [phase-2.md](phase-2.md) — доставка: CDN, edge API, npm.
- [phase-3.md](phase-3.md) — пакет для разработчиков.
- [phase-4.md](phase-4.md) — сайт MVP и MCP-сервер.
- [adr/](adr/README.md) — архитектурные решения: сводка, отдельный файл на каждое решение и продуктовые решения по фазам.
- [backlog.md](backlog.md) — открытые вопросы и находки: что ждёт решения, что исправить до публикации, ошибки в коде.
- [tests.md](tests.md) — проверки пакета: каждое обещание README и чем оно проверено, что не проверено (шаг 9 фазы 3).

Имена: бренд Iconavo, организация на GitHub iconavo, scope в npm `@iconavo-ui`, веб-компонент `<iconavo-icon>`, домен `iconavo.dev` — выбран 21 октября 2026, зарегистрирован на Cloudflare (ADR-0004). Адреса вида `api.домен`, `cdn.домен` и `mcp.домен` — заглушки: вместо «домен» подставляется `iconavo.dev`.

Главная документация — эта папка: с 19 октября 2026 планы и решения правятся только здесь. Документ «Roadmap запуска платформы иконок» в Claude — исходная версия от 17 октября 2026, он больше не обновляется. Схемы остались только в нём: сюда их не переносили.

# ADR-0017. Метаданные и лицензии

Статус: технические части приняты 15 октября 2026 по рекомендации, продуктовые ждут вашего подтверждения.

Вопрос: откуда берутся сведения об авторах, лицензиях, тегах и категориях и как они проверяются?

Решение:

- Лицензия набора хранится полностью: SPDX-идентификатор из пакета автора, текст LICENSE, файл NOTICE (если есть), ссылка на источник и коммит.
- При первом добавлении набора лицензию подтверждает человек. Дальше конвейер останавливается, если она изменилась у автора.
- Автор, ссылка и признак цветного набора записываются в `info.json`, как у Iconify.
- Теги и категории авторов импортируются как есть — до очистки SVG, если лежат прямо в файлах. Они приводятся к строчным буквам, дубли удаляются.
- Если тегов нет, базовые берутся из частей имени, остальное добавляет обогащение (ADR-0020).

Продуктовые решения — за вами:

- Категории на сайте. Рекомендация: на старте показываем авторские категории каждого набора, а единые категории для всех наборов — кандидат в фичи фазы 4.
- Образцы для витрины набора. Рекомендация: шесть иконок выбираются автоматически, вы можете заменить их вручную.

Почему: лицензия — юридическая основа каждого пакета, а теги — сырьё для поиска.

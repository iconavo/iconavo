# ADR-0012. Реестр источников и загрузка

Статус: принято 15 октября 2026 по рекомендации, с опорой на Iconify.

Вопрос: откуда и как конвейер забирает наборы, чтобы обновления шли автоматически и давали одинаковый результат?

Решение:

- Только источники, которые скачиваются автоматически: npm-пакет или git-репозиторий автора. По тому же правилу наборы отбирает Iconify ([источник](https://github.com/iconify/icon-sets/blob/master/CONTRIBUTING.md)).
- Figma как источник не используем: у Iconify обновления из Figma остановились из-за лимитов API ([источник](https://iconify.design/news/2025.html)).
- Один конфиг на набор в `sources/{префикс}.ts`: источник, путь к SVG, правила имён, варианты, монохромный или цветной, лицензия, откуда брать теги. TypeScript позволяет Claude Code проверять поля конфига автоматически.
- Версии закреплены в файле `sources.lock.json`: версия npm-пакета или хэш коммита. Обновление набора — это изменение одной строки в этом файле.
- Загрузка кэшируется по версии: если версия не изменилась, набор не скачивается и не пересобирается.

Уточнение от 17 октября 2026: Lucide берётся из git-репозитория, а не из npm-пакета `lucide-static`. В пакете лежат ещё 268 копий под старыми именами (например, `activity-square` — старое имя `square-activity`), и они стали бы дубликатами в каталоге. В репозитории 1891 иконка, и у каждой есть `{имя}.json` с тегами и списком старых имён: из них получаются алиасы (ADR-0005). Для этого в конфиге набора есть поле `iconMetadata: "json"`.

Уточнение от 18 октября 2026: варианты Tabler, Material Symbols, Phosphor и Fluent Emoji лежат в разных папках источника, часто с одинаковыми именами файлов. Поэтому вместо одной папки конфиг набора содержит список `svgFolders`: у каждой папки свой путь и свои правила имён, а суффикс варианта добавляется заменой (`$` → `-filled`). В пути `*` заменяет ровно одну его часть: у Fluent Emoji папки `assets/*/Flat` и `assets/*/*/Flat` (с оттенком кожи). Два файла с одним итоговым именем по-прежнему останавливают конвейер. Из Material Symbols берётся вес 400 и три формы; из Fluent Emoji — только Flat, через git, потому что пакета npm нет.

Уточнение от 20 октября 2026 (шаг 7 фазы 1):

- Поля `iconMetadata` и `tagsFile` заменило поле `metadata` — формат метаданных автора (`lucide`, `tabler`, `phosphor`, `fluent-emoji`). Какие файлы скачивать для формата, задаёт код (`METADATA_FILES`). Ещё в конфиге появились `author`, `license.confirmed`, `suffixes` и `samples` (ADR-0017).
- NOTICE в корне источника скачивается всегда, если он есть.
- В метке кэша записаны правила скачивания. Если они изменились, набор скачивается заново, даже когда версия та же. Ключ кэша в CI учитывает и код загрузчика.
- git-источники скачиваются без перевода строк под систему (`-c core.autocrlf=false -c core.eol=lf`): тексты лицензий и JSON одинаковы на Windows и Linux.

Почему: одна и та же версия источника всегда даёт один и тот же результат, а каждое обновление видно и понятно.

Последствия: шаг 2 фазы 1 строится по этой схеме, новый набор добавляется одним конфигом.

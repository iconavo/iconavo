# ADR-0036. Документация и бета

Статус: технические части приняты 16 октября 2026 по рекомендации, продуктовые подтверждены владельцем.

Вопрос: как разработчики узнают о пакете и как выходит первая версия?

Решение:

- README пишется до кода (шаг 1 фазы 3) и становится основой документации.
- Документация: быстрый старт, справка по атрибутам и функциям, рецепты — свой хост, работа без сети, серверный рендер.
- Живые примеры на StackBlitz для HTML, React и Next.js.
- Бета 0.1.0 выходит под тегом `next` (ADR-0026) с журналом изменений; до версии 1.0 API может меняться (ADR-0005).
- Перед публикацией — проверки `/code-review` и `/security-review` в Claude Code.

Продуктовые решения — за вами:

- Лицензия ваших пакетов. Рекомендация — MIT, как у пакетов Iconify ([источник](https://github.com/iconify/iconify)): открытый код повышает доверие и помогает распространению.
- Публичная бета. Рекомендация — пакеты под тегом `next` доступны всем, но без анонса до запуска.
- Где живёт документация. Рекомендация — раздел `/docs` на основном сайте: одна точка входа и общий бренд.

Уточнение от 20 октября 2026: решения владельца — в сводке решений (лицензия MIT, публичная бета под тегом `next` без анонса, документация в `/docs` сайта).

- Репозиторий открыт раньше беты — 20 октября 2026, перед шагом 9 фазы 1. На бесплатном тарифе GitHub закрытый репозиторий не даёт защиту `main` и автослияние PR (шаг 9, ADR-0019), а npm ставит подпись provenance только при публикации из открытого репозитория (ADR-0026).
- Открыт как есть, со всей историей разработки: документацией, CLAUDE.md и PR. Просто удалить файлы не скрыло бы их — они остались бы в истории git и в PR.
- В корне — `LICENSE`: MIT, Copyright (c) 2026 Konstantin Yanakhmetov. У наборов иконок в `data/` — лицензии их авторов (ADR-0017).
- Защита `main` включена: только через PR с зелёными проверками «CI» и «Данные».

Почему: разработчик выбирает библиотеку за несколько минут, и эти минуты он проводит в документации.

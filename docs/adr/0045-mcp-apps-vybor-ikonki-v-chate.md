# ADR-0045. MCP Apps: выбор иконки в чате

Статус: технические части приняты 16 октября 2026 по рекомендации, продуктовая ждёт вашего подтверждения.

Вопрос: как человек выбирает иконку прямо в разговоре с ассистентом?

Решение:

- Шестой инструмент `pick_icon` объявляет интерфейс — ресурс `ui://picker` по спецификации MCP Apps ([источник](https://github.com/modelcontextprotocol/ext-apps)).
- Клиент показывает сетку прямо в чате, в защищённой рамке. Клик по иконке возвращает выбор ассистенту, и он вставляет код.
- Интерфейс собирается на SDK `@modelcontextprotocol/ext-apps`. Для Claude Code в том же репозитории есть готовые навыки `create-mcp-app` и `add-app-to-server`.
- Такие интерфейсы показывают Claude, ChatGPT, VS Code и другие совместимые клиенты. Где поддержки нет, ассистент получает обычный ответ с картинкой-превью.
- Стили сетки берутся из дизайн-токенов сайта (ADR-0038).

Продуктовое решение — за вами: сетка выбора. Рекомендация — 12 вариантов, переключатель стиля, предпросмотр в выбранном цвете и кнопка «Выбрать»; визуал — по вашим макетам.

Почему: ИИ часто берёт не ту иконку, а выбор человеком прямо в чате решает эту проблему за один клик.

# ADR-0054. Настройки сетки: вид, размер иконок, иконок на странице

Статус: принято 23 ноября 2026 (редизайн по макетам Figma, раздел «Настройки»). Решения владельца — функции панели целиком: виды «крупная сетка» и «список» собрать самим (в макете их нет), ползунок Icon Size — размер иконки в плитке, потолок API поиска поднять, кнопка сброса — Reset Settings; остальное — по рекомендации.

Вопрос: как устроить панель Settings из макета «Настройки» (кадры «Settings — Start Scenario», «Settings / Opened Panel» и их телефонные пары), если крупная сетка, список и сетка с другим размером иконок в макете не нарисованы, а 144 и 192 иконки на странице поиска не помещаются в ответ API (до 120 за раз)?

## Решение

### Где и как открывается

- **Кнопка Settings** — в строке поиска страницы набора и выдачи поиска (`GridSettings`, `components/catalog/GridToolbar.tsx`); на телефоне и в узкой строке — квадратная шестерёнка 46 × 46 справа от поиска.
- **На телефоне строка поиска — в одну строку**, как в кадре «Settings / Mobile — Start Scenario» (решение владельца 23 ноября 2026): поле, у выдачи — фильтр, и шестерёнка, по 46 px с зазорами 8 px (поле 250 px при ширине 390). Переключателя вида там нет — вид на телефоне выбирают в шторке настроек; прежде фильтр и вид стояли вторым рядом.
- **Панель** (`components/settings/SettingsPanel.tsx`) устроена как рюкзак (ADR-0042): на компьютере — справа во всю высоту поверх страницы, 320 px, немодальная, сетку рядом можно листать; на телефоне — шторка снизу по высоте содержимого, с ручкой и затемнением.
  - Закрывают ✕, Esc, кнопка Settings и щелчок мимо панели (решение владельца 23 ноября 2026): само нажатие срабатывает — щелчок по карточке убирает настройки и открывает панель иконки; на телефоне — ещё протяжка ручки вниз и тап по затемнению. Так же закрывается и рюкзак (решение владельца того же дня): «в рюкзак» у карточки при открытой панели кладёт иконку и закрывает панель (уточнение ADR-0042). Общий код — `useCloseOnOutsideClick` в `lib/panel-store.ts`.
  - У панели на компьютере — небольшая тень влево, на страницу; та же тень — у рюкзака (решение владельца 23 ноября 2026). Токен `--shadow-panel`: два слоя, как у шторки настроек в макете (−2 0 6 и −12 0 32), вдвое прозрачнее макета (решение владельца): в тёмной теме — 8% и 16% чёрного, в светлой — 4% и 6%.
  - **Закрытие — с анимацией**, у настроек и у рюкзака (решение владельца 23 ноября 2026): панель уезжает вправо за `--motion-panel-out` (180 мс), шторка на телефоне — вниз за `--motion-sheet-out` (220 мс), затемнение гаснет; кривая — `--motion-ease-in`, как у ухода панели иконки; при «уменьшить движение» — сразу. Пока панель уезжает, у неё `data-closing` (нажатия её не задевают), а отметка `data-side-panel` у `<html>` — одна на обе панели — держит полосу прокрутки страницы спрятанной: панель не дёргается на ширину полосы. Код — `useSidePanel` в `lib/panel-store.ts`.
  - Фокус — на заголовок при открытии и обратно на кнопку при закрытии; Esc закрывает настройки раньше панели иконки.
  - Кнопки «Применить» нет: выбор действует сразу (заметки макета).
- **Рядом с рюкзаком открытой бывает только одна панель** (`lib/panel-store.ts`): справа они занимают одно место. Открытие одной закрывает другую; кнопка закрытой забывается — фокус уходит в новую панель.

### Что в панели

| Раздел | Что выбирает | По умолчанию |
| --- | --- | --- |
| View | Small Grid · Large Grid · List of Icons | Small Grid |
| Icon Size | размер иконки в плитке, 16–96 px шагом 4 | 24 px; у крупной сетки — 48, пока ползунок не трогали |
| Icons Per Page | 48 · 96 · 144 · 192 | 48 на телефоне, 96 на компьютере (заметки макета) |

- **Reset Settings** внизу сбрасывает только эти настройки; фильтры поиска не трогает. В макете кнопка подписана Reset Filters — подпись заменена (решение владельца).
- Тот же выбор вида — у переключателя из трёх значков рядом с поиском, а числа на странице — у меню «Icons per page: N ▾» над сеткой (на телефоне меню нет, число меняют только настройки).
- Кружки — родные radio, невидимые поверх строки: щелчок по строке, стрелки, Пробел и экранный диктор работают сами. Ползунок — родной `<input type="range">`.

### Виды (макета нет — собраны из Icon Card)

- **Разметка плиток у всех видов одна**, вид меняют стили по `data-grid-view` у `<html>`. Колонки у каждого вида свои и — как у мелкой сетки — только от ширины окна (решение владельца 13 ноября 2026), по той же формуле: n колонок — с окна n·(плитка + зазор) − зазор + 19rem.
  - Мелкая сетка — как была: плитка не уже 8,75rem, 7 колонок при 1440 px.
  - Крупная сетка: плитка не уже 16,25rem (4 колонки при 1440 px, 2 до 64rem), поля 32/16, иконка 48 px, имя 14/18.
  - Список: строка не уже 20rem (3 колонки при 1440 px, 1 до 64rem) — иконка слева, имя, у выдачи справа набор; кнопки «в рюкзак» и выбора — справа.
- **Размер иконки** — CSS-переменная `--tile-icon`; высота плитки и скелетона растёт вместе с ним, у всех клеток страницы одна: замена скелетонов карточками не двигает сетку.

### Хранение и первая отрисовка

- Настройки — в `localStorage` браузера (`iconavo-grid`, только отличия от умолчаний), как тема (ADR-0038); на сервер не уходят, выбор в другой вкладке приходит событием storage. Код — `lib/grid-settings.ts`.
- Вид и размер ставит у `<html>` скрипт в `<head>` (`lib/grid-script.ts`, рядом со скриптом темы) до первой отрисовки. Серверный HTML сразу встаёт в нужный вид — без мигания и без расхождения с гидратацией. Подсветка переключателя вида тоже идёт от этого атрибута.
- Число на странице знает только браузер: сервер, как и прежде, рисует первые 96 карточек набора, браузер дорисовывает или убирает лишние после гидратации; поиск и так ждёт колонок.

### Число на странице

- **Целыми рядами, как и прежде** (решение владельца 13 ноября 2026): выбранное число — цель, `pageSizeFor(колонки, цель)` даёт ближайшее число целых рядов. При 7 колонках варианты — 49, 98, 147, 189; при 3 и 6 колонках — ровно 48, 96, 144, 192. В панели и меню показаны числа, которые встанут на страницу при этой ширине.
- **Смена числа сохраняет первую иконку страницы на экране:** номер страницы в адресе пересчитывается (`keptPage`). Смена колонок — окно, вид — номер не трогает, как раньше.
- **Потолок API поиска — 210 результатов за запрос** (`LIMIT_MAX`, было 120, ADR-0049): при 192 и до 32 колонок страница — не больше 203 карточек. Тест сайта сверяет все варианты с потолком.

Почему: дизайнеру нужно рассмотреть иконки крупнее или пролистать набор быстрее — это настройки сетки, а не страницы, поэтому они помнятся между наборами и поиском. Стили вместо разной разметки дают нужный вид с первого кадра, а одна сетка с разными лестницами колонок не ломает правило «колонки — только от ширины окна» и всё, что на нём стоит: целые ряды, панель иконки без прыжков сетки.

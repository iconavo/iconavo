# ADR-0007. Стек

Статус: принято 15 октября 2026 по рекомендации; поисковый движок и модель эмбеддингов подтверждаются замером в фазе 1.

Вопрос: на каких технологиях строится проект?

| Часть | Выбор | Почему |
| --- | --- | --- |
| Репозиторий | Монорепозиторий на TypeScript с pnpm workspaces | Так устроен и Iconify; стандарт для npm-пакетов |
| Сайт | Next.js на Vercel | Больше всего примеров, Claude Code в нём уверен, сайт заодно проверяет React-адаптер |
| Статика и edge API | Cloudflare: R2 и Workers | Нет платы за исходящий трафик из R2, edge-функции у того же провайдера |
| Второй хост статики | Bunny CDN | Независимый провайдер с простой настройкой |
| Поиск | Meilisearch Cloud на старте | Гибридный поиск, опечатки и фильтры из коробки, без своего сервера |
| Эмбеддинги, короткий список | OpenAI text-embedding-3-large, Google Gemini Embedding, открытая BGE-M3 | Две облачные модели и одна открытая; побеждает лучшая на эталоне |
| Обогащение | Модель с пониманием изображений через пакетный API, например Claude Haiku 4.5 | Быстро и недорого для описаний и синонимов |
| Проверки | Biome, Vitest, Playwright, size-limit | Линтер и форматирование одним инструментом, тесты, бюджет размера |

Перед выбором моделей уточните их актуальные версии и цены: эта область быстро меняется.

Последствия: CI фазы 0 настраивается на Biome, Vitest и size-limit, а аккаунты Cloudflare, Bunny, Vercel и Meilisearch создаются в фазах 1–2.

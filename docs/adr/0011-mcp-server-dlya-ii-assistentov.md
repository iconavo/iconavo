# ADR-0011. MCP-сервер для ИИ-ассистентов

Статус: принято 15 октября 2026, интерактивный выбор через MCP Apps — вторым шагом.

Вопрос: как ИИ-ассистенты находят и вставляют иконки из платформы?

Решение:

- Удалённый MCP-сервер по адресу `mcp.вашдомен` поверх того же edge API и поиска. Его подключают по ссылке в Claude, ChatGPT, Cursor и Claude Code.
- Доступ без ключа с лимитами запросов, ключ — для активного использования.
- В каждом ответе — лицензия и автор иконки.

| Инструмент | Что делает |
| --- | --- |
| `search_icons` | Поиск по смыслу с фильтрами; в ответе имена, лицензия и превью-картинка |
| `get_icon` | SVG или компонент React и Vue с размером, цветом и толщиной линии |
| `get_matching_set` | Несколько иконок в одном стиле за один вызов |
| `get_usage` | Код подключения через ваш пакет |
| `list_sets` | Наборы с лицензиями и стилями |

Второй шаг — MCP Apps: ассистент показывает сетку вариантов прямо в чате, человек кликает нужную иконку, выбор возвращается ассистенту. Это расширение протокола со стабильной спецификацией от 26 января 2026; интерфейс показывается в Claude, ChatGPT и других совместимых клиентах ([репозиторий спецификации](https://github.com/modelcontextprotocol/ext-apps)). Там же лежат готовые навыки для Claude Code, которые помогают собрать такое приложение.

Конкуренты: MCP-серверы для иконок уже есть — несколько поверх API Iconify, сервер Icons8, серверы с поиском по нескольким библиотекам ([каталог](https://lobehub.com/mcp?q=icons)). Отличаться нужно качеством поиска на русском и других языках, выбором иконки в чате, согласованными наборами и лицензиями в ответах.

Последствия: MCP делается в фазе 4 после edge API и поиска, бета MCP — в фазе 5, публикация в каталогах MCP — в фазе 7.

# Решения (ADR)

Здесь записаны архитектурные решения проекта. Технические решения принимаются по рекомендации, а продуктовые отмечены отдельно и остаются за вами. Каждое решение — отдельный файл в этой папке, а CLAUDE.md ссылается на неё.

## Сводка решений

Главный принцип: где Iconify уже нашёл проверенное решение, берём такое же устройство, а отличаемся там, где это ценно для пользователей, — поиском и MCP. Код, данные и серверы при этом остаются вашими.

| ADR | Решение коротко |
| --- | --- |
| 0001. Имя иконки | `набор:иконка`, префиксы как у Iconify |
| 0002. Варианты | Отдельные имена с суффиксами плюс карта суффиксов для группировки |
| 0003. Схема данных | Файлы совместимы с IconifyJSON, данные поиска — в отдельном `search.json` |
| 0004. Адреса | API с адресами как у Iconify на `api.домен`, статика на `cdn.домен`, MCP на `mcp.домен` |
| 0005. Версии | Иконки не удаляются, пакеты по semver, старые версии статики хранятся год |
| 0006. Доставка | Статика на CDN плюс edge API |
| 0007. Стек | TypeScript и pnpm, Next.js, Cloudflare, Meilisearch, три модели эмбеддингов на выбор |
| 0008. Первые наборы | Lucide, Tabler, Material Symbols, Phosphor, Fluent Emoji Flat |
| 0009. Поиск | Гибридный: текстовый плюс векторный, многоязычный |
| 0010. Обогащение | Описания и синонимы от ИИ, эмбеддинги, кэш по отпечатку |
| 0011. MCP | Удалённый сервер с пятью инструментами, затем выбор иконки в чате |
| 0012. Источники | Только npm и git, конфиг на набор, версии закреплены в lock-файле |
| 0013. Очистка | Свой санитайзер по белому списку, шаги как в Iconify Tools |
| 0014. Нормализация | Сетка 24 или 32, атрибуты корня во внешнем g, цвет как у текста, предсказуемые ID |
| 0015. Оптимизация | SVGO с закреплённой версией, три знака после запятой, побайтно одинаковые сборки |
| 0016. Контроль качества | Рендер через resvg, пороги для пустых, обрезанных и изменённых иконок, сверка с оригиналом |
| 0017. Метаданные | Полная лицензия с текстом и NOTICE, теги авторов, подтверждение лицензии человеком |
| 0018. Журнал изменений | Отпечатки SHA-256, журнал выпусков, переименования становятся алиасами |
| 0019. Автообновление | Ежедневная проверка, изменения через PR, автослияние только безопасных |
| 0020. Правила обогащения | По базовой иконке, строгий JSON, лимит стоимости, выборочная проверка |
| 0021. Эталон поиска | 200 запросов от ИИ, рабочая и контрольная части, главная метрика Hit@5 |
| 0022. Выкладка статики | Сначала файлы, потом сверка, манифест последним; откат за минуту |
| 0023. Заголовки | Год для статики, 5 минут для манифеста, неделя для API, CORS для всех |
| 0024. Edge API | Workers поверх R2, ответы как у Iconify, лимиты только для поиска |
| 0025. Второй хост | Bunny CDN, переключение в ядре пакета, ежедневная сверка |
| 0026. Публикация в npm | Пакет на набор, только из CI с provenance, тег next до запуска |
| 0027. Поисковый сервис | Meilisearch, документ на базовую иконку, запросы через API с кэшем и лимитами |
| 0028. Мониторинг | Проверки каждые 5 минут, сводки, потолок расходов, двухфакторная защита везде |
| 0029. Пакеты | Общее ядро плюс тонкие адаптеры: веб-компонент и React |
| 0030. Загрузка | Пачки за тик, адрес до 500 символов, запасные хосты, без localStorage |
| 0031. Рендер | Высота 1em, цвет текста, повороты внутри SVG, декоративные по умолчанию |
| 0032. Веб-компонент | Shadow DOM, рисуются только видимые, резерв места, защита от двойной регистрации |
| 0033. React и SSR | React 18 и 19, одинаковая разметка на сервере и в браузере |
| 0034. Сборка | Только ESM, бюджеты 5, 2 и 2 КБ, последние две версии браузеров |
| 0035. Тесты | Vitest, Playwright, визуальное сравнение, сбои сети, доступность |
| 0036. Документация и бета | README до кода, примеры на StackBlitz, бета 0.1.0 под тегом next |
| 0037. Структура сайта | Адрес иконки повторяет её имя, алиасы перенаправляют, служебные слова зарезервированы |
| 0038. Дизайн-система | Макеты в Figma через Figma MCP, токены как CSS-переменные, Tailwind, shadcn/ui, WCAG 2.2 AA |
| 0039. Рендеринг и SEO | Страницы по первому запросу с кэшем, карты сайта по наборам, hreflang |
| 0040. Поиск на сайте | Поиск по мере ввода, группировка вариантов, фильтры в адресе страницы |
| 0041. Страница иконки | Превью с настройками, лицензия с текстом авторства, похожие иконки |
| 0042. Код и экспорт | Шесть вариантов кода и файлов, сумка для мультивыбора, лицензии в архиве |
| 0043. Аналитика | Без cookie, успех поиска как главная метрика, отчёт о неудачных запросах |
| 0044. MCP-сервер | Официальный SDK, Streamable HTTP, Cloudflare Workers, превью-сетка в ответе |
| 0045. Выбор в чате | Инструмент pick\_icon с сеткой по спецификации MCP Apps |

## Решения фазы 0

Все семь решений приняты по рекомендации с опорой на Iconify и записаны выше. Если что-то смущает, пересмотрите их до начала фазы 1.

- [x] ADR-0001. Формат имени иконки: разделитель, символы, имена наборов, правило для конфликтов.
- [x] ADR-0002. Модель вариантов: суффиксы, отдельные наборы или группировка под одной иконкой.
- [x] ADR-0003. Схема данных: поля файла набора и файла метаданных.
- [x] ADR-0004. Схема URL: домен, раскладка, версии в адресах.
- [x] ADR-0005. Политика версий: semver пакетов и срок хранения старых версий на CDN.
- [x] ADR-0007. Стек: фреймворк сайта, поисковый движок, короткий список моделей эмбеддингов.
- [x] ADR-0008. Первые пять наборов и срез вариантов для старта.

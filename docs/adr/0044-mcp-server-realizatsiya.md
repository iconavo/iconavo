# ADR-0044. MCP-сервер: реализация

Статус: технические части приняты 16 октября 2026 по рекомендации; продуктовая — по умолчанию код с вашим пакетом, чистый SVG по запросу — подтверждена владельцем 17 октября 2026 (отметка в [сводке решений](README.md)).

Вопрос: как устроен MCP-сервер из ADR-0011?

Решение:

- Официальный TypeScript SDK протокола MCP, удалённый доступ по Streamable HTTP на `mcp.домен`.
- Сервер работает на Cloudflare Workers рядом с edge API и обращается к нему напрямую.
- Пять инструментов из ADR-0011 с точными описаниями и схемами ответов — так ассистенты реже ошибаются при вызове.
- `search_icons` возвращает имена, лицензии и одну картинку-сетку с превью найденных иконок: модели со зрением видят результат целиком.
- Без входа и ключей, с лимитами из ADR-0024; ключ — для активного использования.
- Инструменты меняются только с добавлением возможностей, чтобы ничего не ломать у подключённых клиентов.
- Проверка — в MCP Inspector и в реальных клиентах: Claude, ChatGPT, Cursor, Claude Code.

Продуктовое решение — владельца, подтверждено 17 октября 2026: что MCP отдаёт по умолчанию. Рекомендация — код с вашим пакетом, а чистый SVG — по запросу ассистента: так MCP приводит разработчиков к пакету.

Почему: ассистенты должны получать иконки так же надёжно, как сайт, но в удобном для себя виде.

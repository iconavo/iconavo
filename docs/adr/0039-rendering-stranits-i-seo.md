# ADR-0039. Рендеринг страниц и SEO

Статус: принято 16 октября 2026 по рекомендации.

Вопрос: как сайт с десятками тысяч страниц остаётся быстрым и находится в поисковиках?

Решение:

- Next.js на Vercel (ADR-0007). Страницы наборов и иконок создаются при первом запросе и кэшируются; после выпуска данных кэш сбрасывается только по изменившимся наборам.
- У каждой страницы иконки свой заголовок, описание из обогащения, канонический адрес и автоматически созданная картинка для соцсетей.
- Карта сайта разбита на файлы по наборам — не больше 50 000 адресов в файле — плюс общий индекс карт.
- Русская и английская версии связаны пометками hreflang, чтобы поисковики показывали нужный язык.
- Страницы результатов поиска не индексируются: у них нет постоянного содержания.
- Бюджет скорости из плана: LCP не больше 2,5 секунды для 75% визитов, Lighthouse не ниже 90.

Уточнение от 29 октября 2026 (шаг 10 фазы 3, [ADR-0050](0050-sayt-dokumentatsii-i-zhivye-primery.md)):

- До запуска 1 июня 2027 сайт скрыт от поисковиков — решение владельца. Метка `noindex, nofollow` стоит и в HTML, и в заголовке `X-Robots-Tag`.
- `robots.txt` обход не запрещает: иначе поисковик не увидел бы саму метку.
- Страницы документации собираются при сборке и статические.
- В фазе 7 нужно сделать вместе: снять метку, сделать карту сайта и канонические адреса.

Уточнение от 30 октября 2026 (шаг 2 фазы 4; решение владельца — пересборка после выкладки):

- **Страницы каталога собираются при сборке и статические**: главная, `/sets`, страницы наборов, `/changelog` и `/licenses` на двух языках. Данные — из edge API (`/collections`, `/collection`, `/changelog`, ADR-0024), поэтому сайт показывает ровно то, что уже выложено на раздачу. Страницы наборов — `generateStaticParams` по `/collections` и `dynamicParams = false`: неизвестный адрес — 404 без запуска функции.
- **О выпуске сайт узнаёт пересборкой.** После каждой успешной «Выкладки» на `main` workflow «Сайт» собирает и выкладывает сайт заново (`workflow_run`, та же защита от запусков из форков, что у поискового индекса, ADR-0049). Пять наборов — минуты сборки, лимит Vercel Hobby — 100 выкладок в сутки.
- **Сброс кэша только по изменившимся наборам** — в шаге 4, когда появятся десятки тысяч страниц иконок: их собирать при каждой выкладке уже долго.
- **Свежесть видна снаружи.** У страницы набора — метка `<meta name="iconavo-version">` с версией данных набора; `pnpm site --live` сверяет её с живым манифестом раздачи (строка «Свежесть данных», ADR-0050).

Почему: страницы иконок приводят людей из поисковиков, а скорость — часть качества продукта.

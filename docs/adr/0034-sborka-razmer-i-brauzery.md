# ADR-0034. Сборка, размер и браузеры

Статус: принято 16 октября 2026 по рекомендации.

Вопрос: в каком виде выходят пакеты, сколько они весят и где работают?

Решение:

- Пакеты выходят только в современном формате модулей ESM с типами TypeScript; старый формат CommonJS не поддерживается.
- Бюджеты размера после gzip: ядро — 5 КБ, веб-компонент сверх ядра — 2 КБ, адаптер React сверх ядра — 2 КБ. CI падает при превышении (size-limit, ADR-0007).
- Пакеты устроены так, чтобы в сборку сайта попадало только то, что действительно используется.
- Поддерживаются последние две версии Chrome, Edge, Firefox и Safari.

Почему: ядро загружается на каждой странице пользователей, и каждый лишний килобайт замедляет чужие сайты.

Последствия: бюджеты можно пересмотреть после первой реализации, но только осознанно, через изменение этого ADR.

Уточнение от 26 октября 2026 (шаг 1 фазы 3, README пакета):

- Для страницы без сборщика в `@iconavo-ui/icon` лежит ещё и самостоятельный ES-модуль с ядром внутри (ADR-0032); его размер меряется отдельно.
- Режим разработки включается условием экспорта `development` (ADR-0031): длинные сообщения и пунктирная рамка живут только в сборке для разработки и не занимают бюджет рабочей.
- Цифр размера в README нет, пока их не измерит шаг 7.

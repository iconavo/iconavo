# ADR-0046. Обогащение: модель, пакетный API и хранение описаний

Статус: принято 20 октября 2026. Решения владельца — модель, пакетный API, ключ в `.env`, описания только у базовой иконки; остальное — по рекомендации.

Вопрос: как именно конвейер получает описания и синонимы от ИИ (ADR-0010, ADR-0020), чтобы результат воспроизводился в CI без ключей, стоил дёшево и не терялся при обновлениях наборов?

Решение:

- Модель — Claude Haiku 5.5 (`claude-haiku-5-5`) через официальный пакет `@anthropic-ai/sdk`; запросы уходят пакетом через Message Batches API: вдвое дешевле обычных запросов, лимиты скорости не мешают, результат приходит обычно за минуты, самое большее за сутки. Цены на 20 октября 2026: $0,05 за миллион входных и $0,25 за миллион выходных токенов при промпте до 100 000 токенов. Картинка 256×256 стоит 100 визуальных токенов.
- Команда — `pnpm enrich [набор…]`, отдельная от сборки: `pnpm data` сеть не использует и в CI должен давать побайтно те же файлы. Ключ `ANTHROPIC_API_KEY` берётся из окружения (команда подхватывает `.env`), в вывод не попадает.
- Хранение — `search.json`: поля `ru`, `en` и `promptVersion` у базовой иконки (ADR-0002). У вариантов этих полей нет: сайт, поиск и эмбеддинги берут описание базовой иконки по карте суффиксов. Это уточнение к ADR-0020: «результат переносится на варианты» при индексации, а не в файле, иначе `search.json` Material Symbols вырос бы с 2 до 18 МБ.
- Кэш — тот же `search.json`. Сборка переносит описания с диска базовым иконкам с тем же отпечатком (ADR-0018), переименования — по журналу. Ключ — имя, а не отпечаток: один рисунок бывает под разными именами (`circle` и `wash-dryclean` у Tabler, 92 пары у Material Symbols), и описания у них разные. Рисунок изменился — описание пропадает до следующего `pnpm enrich`. Файл на диске не по схеме или от другого набора — «СТОП» набора: молча потерять оплаченные описания нельзя.
- Что отправляется: PNG 256×256 (белый фон, рисунок чёрным, отступ 1/16 холста), название набора, имя иконки и теги автора. Системный промпт — на английском с русскими примерами разговорных слов; ответ — строгий JSON по схеме (`output_config.format`); мышление адаптивное, усилие `low`, `max_tokens` 4096. Версия промпта — `PROMPT_VERSION` в коде, пишется в `promptVersion`; новая версия старые записи не трогает (ADR-0020).
- Проверка ответа: текст берётся по типу блока (первыми могут идти блоки мышления), JSON проходит схему, синонимы чистятся — строчные буквы, без повторов, пустых и самого имени, — и их должно остаться 5–10 (`languageSchema`). Отказ модели, обрезанный ответ, ошибка или истечение пакета — отказ с причиной в отчёте; такие иконки отправляются в следующий раз.
- Выборка: без `--limit` — все базовые иконки без описаний; `--limit=N` — постоянная случайная выборка из N базовых по хэшу имени, как выборка в отчёте метаданных. Повторный запуск с тем же N ничего не отправляет: описания у выборки уже есть.
- Стоимость: до отправки — оценка по константам с запасом (1200 входных и 500 выходных токенов на запрос) по сумме всех выбранных наборов; выше `--max-cost` (по умолчанию $5) — ничего не отправляется. Факт — по `usage` ответов; в отчёте среднее на иконку и прогноз на остаток набора и каталога.
- Состояние пакета — `.cache/enrich/{набор}/batch.json`, не в git: прерванный запуск или запуск с `--no-wait` продолжаются с опроса результатов, повторно ничего не отправляется. Результат иконки, чей отпечаток изменился после отправки, отбрасывается. Состояние удаляется только после записи `search.json`.
- Отчёт — `.cache/reports/enrich/index.html`: карточки с иконкой и PNG, который видела модель, описаниями и синонимами, список отказов, стоимость и прогноз; «Что проверить» — по ADR-0020.
- Код — `packages/pipeline/src/enrich/`; перенос описаний в сборке — `enrich/apply.ts`, его вызывает `metadata/run.ts`.

Проверено на выборке 20 октября 2026: 50 иконок Lucide — получено 50 из 50, отказов 0; стоимость $0,0056 — 55 053 входных токена (≈1 100 на иконку) и 11 570 выходных (≈230 на иконку при усилии `low`). На иконку ≈ $0,00011, весь каталог из 15 669 базовых иконок — около $1,75. Константы оценки после прогона — 1 200 входных и 500 выходных токенов на запрос, вдвое больше факта по выходу: оценка каталога ≈ $2,9, под лимитом $5. Качество описаний на выборке проверяет владелец по отчёту (ADR-0020); выборка принята 20 октября 2026.

Полный прогон 20 октября 2026: пять пакетов на 15 619 базовых иконок обработаны за 17 минут, получено 15 618, один отказ (`ph:golf` — ответ без русских синонимов, отправлен повторно). Стоимость $1,73: 17,1 млн входных и 3,5 млн выходных токенов, на иконку ≈ $0,00011. `search.json` пяти наборов выросли в сумме с 6,6 до 21,2 МБ.

Почему: описания — основа смыслового поиска, а значит главный расход на ИИ; пакетный API и самая дешёвая модель с пониманием картинок делают весь каталог (15 669 базовых иконок) вопросом нескольких долларов, а хранение в `search.json` по имени с проверкой отпечатка не требует ни нового файла, ни ключей в CI.

Последствия:

- Робот обновления (ADR-0019) описаний не делает: у изменённых и новых иконок они появятся после ручного `pnpm enrich {набор}` в `main`. Обогащение в CI с ключом в секретах — отдельное решение владельца.
- Фильтр запрещённых слов (ADR-0010) появится после ручной проверки первых выборок.
- Оттенки кожи Fluent Emoji — отдельные базовые иконки, как у Iconify, и описания у них свои. В поиске они — одна карточка с базовым эмодзи (решение владельца 21 октября 2026, ADR-0048).
- Полное переобогащение при новой версии промпта — отдельный флаг, когда понадобится.
- Пакет, отправленный за мгновение до сбоя записи состояния, в коде не ищется: его видно в консоли Anthropic в списке пакетов.

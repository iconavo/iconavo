# ADR-0018. Отпечатки, журнал изменений и переименования

Статус: технические части приняты 15 октября 2026 по рекомендации, продуктовая ждёт вашего подтверждения.

Вопрос: как узнавать, что именно изменилось в наборе, и не ломать старые имена иконок?

Решение:

- Отпечаток иконки — SHA-256 от нормализованного тела и размеров, первые 12 символов.
- Версия набора — отпечаток отсортированного списка отпечатков иконок, первые 8 символов. Она же стоит в адресах статики (ADR-0004).
- Журнал ведётся на каждый выпуск набора: добавлены, изменены, скрыты, переименованы. Два формата: markdown для людей и JSON для сайта.
- Переименование определяется автоматически: старое имя исчезло, а иконка с тем же отпечатком появилась под новым. Старое имя становится алиасом, иконка не удаляется (ADR-0005).
- Скрытия и переименования выделяются в pull request отдельным блоком, чтобы их было видно при одобрении.

Продуктовое решение — за вами: публичная лента «Что нового» на сайте. Рекомендация — да, данные для неё уже есть в журнале.

Почему: пользователи видят, что изменилось, а старый код с прежними именами продолжает работать.

# Бэклог: открытые вопросы и находки

Записано 18 октября 2026, после шага 4 фазы 1; обновлено 19 октября, после шагов 5 и 6, и 20 октября, после шага 7. Здесь то, что выяснилось в работе, но ещё не стало решением в ADR или кодом. Каждый пункт закрывается отдельным шагом с коммитом. Закрытый пункт отмечается `[x]` или удаляется, а итоговое решение записывается в ADR.

## Ждут вашего решения

- [x] **SVGO для шага 5.** Решено 19 октября 2026: да. Версия 4.1.0 закреплена точно и нужна только конвейеру (уточнение к ADR-0015).

- [x] **Одинаковые варианты Material Symbols — алиасами, как у Iconify.** Решено 19 октября 2026: да. Сделано на шаге 5: 15 756 иконок и 7 818 алиасов; правило и сверка с Iconify — в ADR-0002.

- [x] **Бесплатный тариф GitHub и закрытый репозиторий мешают планам.** Решено 19 октября 2026: открыть репозиторий перед шагом 9. Проверено по документации GitHub и npm:
  - **Шаг 9 фазы 1 (ADR-0019).**
    - Автослияние PR в закрытых репозиториях на GitHub Free недоступно.
    - PR, открытый роботом CI со стандартным токеном (`GITHUB_TOKEN`), не запускает проверки — нужен отдельный токен. Он понадобится и в открытом репозитории.
  - **Шаг 5 фазы 2 (ADR-0026).** Подпись provenance в npm ставится только при публикации из публичного репозитория.
  - До открытия:
    - тексты лицензий наборов должны лежать в `data/` — сделано на шаге 7;
    - нужен файл `LICENSE` в корне;
    - нужно проверить историю git на секреты.
  - После открытия: поправить правило о закрытом репозитории в CLAUDE.md и ADR-0036 и включить защиту `main`.

- [ ] **Четыре иконки Material Symbols выходят за холст в самом источнике.**
  - Это `handshake-outline-sharp`, `satellite-alt-sharp`, `satellite-alt-outline-sharp` и `zone-person-urgent-sharp`. Нашёл контроль качества на шаге 6.
  - У Google часть рисунка лежит за краем холста: например, у `handshake` точка стоит на x = −44 при холсте 0…960. Браузер эту часть обрезает.
  - У Iconify в этих иконках рисунок тоже выходит за холст: у `handshake-outline-sharp` до x = −1,1 на сетке 24. Проверено по их API 19 октября 2026.
  - Наша сборка ничего не испортила: сверка с оригиналом отличий не нашла.
  - Варианты:
    - оставить как есть (рекомендация) — иконки останутся в отчёте как напоминание;
    - сообщить Google;
    - когда появится список известных находок, отметить их «так задумано автором».
  - Когда: до первой публикации (фаза 2).

- [ ] **У Material Symbols нет тегов и категорий автора.**
  - В пакете npm их нет: на шаге 7 теги взяты из частей имени, категорий нет. Это 15 756 иконок, 44% каталога.
  - Полные теги и категории есть только по живому адресу Google (`fonts.google.com/metadata/icons`). Его нельзя закрепить по версии, поэтому по ADR-0012 он не подходит.
  - Варианты:
    - оставить как есть (рекомендация): описания и синонимы даст обогащение на шаге 10;
    - сделать исключение: снимок данных Google хранить в репозитории и обновлять вручную.
  - Когда: после первого замера поиска на шаге 12 — по цифрам будет видно, проседает ли Material Symbols.

- [x] **Где главная документация.** Решено 19 октября 2026: в репозитории. Это записано в `docs/README.md`, ссылки между файлами `docs/` ведут на файлы репозитория, а в документе в Claude стоит пометка, что он больше не обновляется.

## Исправить до первой публикации (фаза 2)

После публикации имена иконок не удаляются (ADR-0005): ошибка останется навсегда хотя бы алиасом.

- [ ] **`material-symbols:format-color` — неверное имя.**
  - Должно быть `format-color-fill-outline`: это контурный вариант иконки `format_color_fill`, ведро с краской. Затронуты 3 имени — обычное, rounded и sharp.
  - Причина: в `sources/material-symbols.ts` правило сначала меняет `_` на `-`. После этого конец названия `_fill` не отличить от пометки залитого варианта `-fill`.
  - Исправление: замену `_` → `-` поставить последней. После правки сверить имена с Iconify. Должны остаться только расхождения версий: `done-outline*` есть только у нас, `power-plug*` — только у Iconify.

- [ ] **`fluent-emoji-flat:pinata` — у Iconify `piata`.**
  - Правило `ñ` → `n` в `sources/fluent-emoji-flat.ts` даёт имя, которого нет у Iconify. Ассистент, который пишет имя по памяти, промахнётся.
  - Рекомендация: основное имя как у Iconify (`piata`), а `pinata` добавить алиасом, когда появятся алиасы (шаг 8).

## Ошибки в коде — сейчас не мешают

- [ ] **Валидатор пропускает алиас на несуществующую иконку `constructor`.**
  - Где: `packages/schema/src/cross.ts`, функция `checkNamesAndAliases`.
  - Причина: проверка через `in` видит встроенные свойства объекта.
  - Исправление: `Object.hasOwn`.
- [ ] **Санитайзер считает опасным закодированный перевод строки внутри контура.**
  - Где: `packages/pipeline/src/sanitize/policy.ts`, функция `checkValue`. Речь о `&#10;`, `&#9;`, `&#13;` в значении атрибута.
  - Последствие: атрибут удаляется, а весь набор останавливается с пометкой «признак подмены источника».
  - В пяти наборах такого нет, но при расширении каталога до 15–25 наборов (фаза 5) будут ложные тревоги.
  - Исправление: такие символы заменять пробелом.
- [ ] **Конфликт имён не останавливает загрузку.**
  - Где: `packages/pipeline/src/cli.ts`, команда `fetch`.
  - Сборка (`pnpm data`) с шага 5 останавливает набор при конфликте имён. А загрузка конфликт и нарушение правила имён только печатает и завершается успешно, хотя по ADR-0001 должна остановиться.
  - Когда: до шага 9, где решения принимает CI.
- [ ] **В `info.json` разрешены лишние поля.**
  - Где: `packages/schema/src/info.ts` (`looseObject`).
  - CLAUDE.md говорит, что в наших файлах лишние поля запрещены. Значит, опечатка в необязательном поле пройдёт незамеченной.
  - Решить: сделать схему строгой или записать исключение (совместимость с форматом Iconify).
- [ ] **Минимальная версия Node указана неточно.**
  - В `package.json` стоит `"node": ">=22"`. Но конвейер читает конфиги `sources/*.ts` напрямую, а это работает только с Node 22.18 и новее.
  - Исправление: указать `>=22.18`.
- [ ] **Повтор файла в архиве npm ломает кэш набора.**
  - Где: `packages/pipeline/src/sources/tar.ts`.
  - Если нужный файл встречается в архиве дважды, он записывается и считается два раза. Число файлов в метке кэша тогда не совпадает с папкой, и набор навсегда остаётся «не скачан».
  - Сейчас не мешает: у Phosphor повторяется `package/./dist/index.umd.js`, а нам нужен только `dist/index.mjs`.
  - Исправление: считать файл один раз.

## Не забыть на шаге 8

- **Алиасы-переименования.**
  - У Iconify есть 268 старых имён Material Symbols после переименований у Google (`ad-units → mobile-text`).
  - Lucide хранит старые имена в JSON рядом с иконками: 268 имён в 257 файлах (поле `aliases`, у каждого пометка `deprecated` и причина: `alias.name`, `alias.duplicate` или `alias.typo`).
  - У Phosphor 18 прежних имён — поле `alias` в списке иконок `dist/index.mjs` (`pulse` ← `activity`).
  - Плюс `pinata` (см. выше).
  - Решить, какие из них брать.
- **Устаревшие иконки Lucide.** Три иконки помечены автором `deprecated` (`badge-swiss-franc`, `receipt-swiss-franc`, `swiss-franc`). Решить, становятся ли они `hidden`, как у Iconify.
- **Отпечатки и ID.** Сделано на шаге 7: отпечаток считается для `search.json`, имя в ID перед подсчётом заменяется заглушкой (ADR-0018). Шагу 8 остаются версия набора, журнал и поиск переименований.

## Не забыть на шаге 9

- **Итог контроля качества для PR из CI.**
  - Сейчас набор со «СТОП» даёт код выхода 1, а подробности есть только в `qc.html`.
  - Для PR из CI (ADR-0019) нужна короткая сводка, которую читает машина, например `qc.json` рядом с отчётом. По ней CI решит, можно ли слить PR автоматически и что вынести в описание.
  - Ещё нужно решить, где хранить `qc.html` из CI, чтобы на него можно было сослаться из PR. Например, как артефакт задачи.

## Позже

- **Указание авторства Feather у иконок Lucide (фаза 4).** LICENSE Lucide — это ISC и раздел MIT для иконок, пришедших из Feather; список таких иконок в нём записан старыми именами. На странице иконки (ADR-0041) у них нужно указывать и Feather.
- **Порядок вариантов на сайте (фаза 4).** В `metadata.json` ключи `suffixes` записаны по кодам символов, а не в порядке Thin → Light → Regular → Bold. Сайту нужен свой порядок.
- **Оттенки кожи Fluent Emoji не сгруппированы.** Как у Iconify, `waving-hand-dark` — отдельная иконка без карты вариантов. Для поиска «один документ на базовую иконку» (ADR-0027) и переключателя на сайте их, возможно, стоит группировать. Решить на шаге 12 или в фазе 4.
- **pixelmatch 8.** Версия 8.0.0 (6 октября 2026) считает цвет иначе (OKLab) и лучше работает с прозрачностью. Обновлять, когда версия проживёт хотя бы несколько недель. При обновлении меняются числа отличий, поэтому пороги ADR-0016 нужно перепроверить на всех наборах.

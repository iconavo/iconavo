# Бэклог: открытые вопросы и находки

Записано 18 октября 2026, после шага 4 фазы 1; обновлено 19 октября, после шагов 5 и 6, и 20 октября, после шагов 7, 8 и 9. Здесь то, что выяснилось в работе, но ещё не стало решением в ADR или кодом. Каждый пункт закрывается отдельным шагом с коммитом. Закрытый пункт отмечается `[x]` или удаляется, а итоговое решение записывается в ADR.

## Ждут вашего решения

- [x] **SVGO для шага 5.** Решено 19 октября 2026: да. Версия 4.1.0 закреплена точно и нужна только конвейеру (уточнение к ADR-0015).

- [x] **Одинаковые варианты Material Symbols — алиасами, как у Iconify.** Решено 19 октября 2026: да. Сделано на шаге 5: 15 756 иконок и 7 818 алиасов; правило и сверка с Iconify — в ADR-0002.

- [x] **Бесплатный тариф GitHub и закрытый репозиторий мешают планам.** Решено 19 октября 2026: открыть репозиторий перед шагом 9. Проверено по документации GitHub и npm:
  - **Шаг 9 фазы 1 (ADR-0019).**
    - Автослияние PR в закрытых репозиториях на GitHub Free недоступно.
    - PR, открытый роботом CI со стандартным токеном (`GITHUB_TOKEN`), не запускает проверки — нужен отдельный токен. Он понадобится и в открытом репозитории.
  - **Шаг 5 фазы 2 (ADR-0026).** Подпись provenance в npm ставится только при публикации из публичного репозитория.
  - До открытия:
    - тексты лицензий наборов должны лежать в `data/` — сделано на шаге 7;
    - нужен файл `LICENSE` в корне;
    - нужно проверить историю git на секреты.
  - После открытия: поправить правило о закрытом репозитории в CLAUDE.md и ADR-0036 и включить защиту `main`.
  - Сделано 20 октября 2026: `LICENSE` в корне (MIT, PR #18), история проверена — секретов нет, репозиторий открыт владельцем как есть, со всей историей. Защита `main` включена, CLAUDE.md и ADR-0036 поправлены. Робот шага 9 работает через приложение GitHub (ADR-0019).

- [ ] **Четыре иконки Material Symbols выходят за холст в самом источнике.**
  - Это `handshake-outline-sharp`, `satellite-alt-sharp`, `satellite-alt-outline-sharp` и `zone-person-urgent-sharp`. Нашёл контроль качества на шаге 6.
  - У Google часть рисунка лежит за краем холста: например, у `handshake` точка стоит на x = −44 при холсте 0…960. Браузер эту часть обрезает.
  - У Iconify в этих иконках рисунок тоже выходит за холст: у `handshake-outline-sharp` до x = −1,1 на сетке 24. Проверено по их API 19 октября 2026.
  - Наша сборка ничего не испортила: сверка с оригиналом отличий не нашла.
  - Варианты:
    - оставить как есть (рекомендация) — иконки останутся в отчёте как напоминание;
    - сообщить Google;
    - когда появится список известных находок, отметить их «так задумано автором».
  - Когда: до первой публикации (фаза 2).

- [ ] **У Material Symbols нет тегов и категорий автора.**
  - В пакете npm их нет: на шаге 7 теги взяты из частей имени, категорий нет. Это 15 753 иконки, 44% каталога.
  - Полные теги и категории есть только по живому адресу Google (`fonts.google.com/metadata/icons`). Его нельзя закрепить по версии, поэтому по ADR-0012 он не подходит.
  - Варианты:
    - оставить как есть (рекомендация): описания и синонимы даст обогащение на шаге 10;
    - сделать исключение: снимок данных Google хранить в репозитории и обновлять вручную.
  - Шаг 10 сделан 20 октября 2026: описания для набора даст `pnpm enrich material-symbols` (ADR-0046, 3 929 базовых иконок).
  - Когда: после первого замера поиска на шаге 12 — по цифрам будет видно, проседает ли Material Symbols.

- [x] **Где главная документация.** Решено 19 октября 2026: в репозитории. Это записано в `docs/README.md`, ссылки между файлами `docs/` ведут на файлы репозитория, а в документе в Claude стоит пометка, что он больше не обновляется.

## Ошибки в коде — сейчас не мешают

- [x] **Валидатор пропускает алиас на несуществующую иконку `constructor`.** Исправлено на шаге 8: `Object.hasOwn` вместо `in` в `packages/schema/src/cross.ts`.
- [x] **Санитайзер считает опасным закодированный перевод строки внутри контура.** Исправлено 20 октября 2026: табуляция и переводы строк в значениях — ссылками `&#9;`, `&#10;`, `&#13;` и внутри CSS — заменяются пробелом, как их читает браузер (`checkValue` в `packages/pipeline/src/sanitize/policy.ts`, ADR-0013).
- [x] **Конфликт имён не останавливает загрузку.** Исправлено 20 октября 2026, до шага 9: `pnpm sources fetch` при нарушении правила имён или конфликте пишет «СТОП» и завершается с кодом 1, как сборка (ADR-0001). Скачанное остаётся в кэше.
- [x] **В `info.json` разрешены лишние поля.** Решено 20 октября 2026: схема строгая, как у `metadata.json` и `search.json` (`packages/schema/src/info.ts`). Файл наш, его читают сайт и MCP; совместимость с IconifyJSON нужна только `icons.json`.
- [x] **Минимальная версия Node указана неточно.** Исправлено 20 октября 2026: в `package.json` — `^22.19.0 || ^24.5.0 || >=26.0.0`.
  - Конвейеру для чтения `sources/*.ts` нужен Node 22.18 и новее, а size-limit из `pnpm check` требует 22.19+, 24.5+ или 26+.
  - Сам pnpm 12 это поле не проверяет, поэтому в `pnpm-workspace.yaml` включён `engineStrict`: на другой версии Node `pnpm install` останавливается с понятной ошибкой.
- [x] **Версии GitHub Actions устарели.** Исправлено 20 октября 2026: во всех workflow — checkout v7, setup-node v7, cache v6, pnpm/action-setup v6, все рассчитаны на Node 24.
  - Ломающих изменений для нас нет: робот отправляет ветку токеном приложения (`persist-credentials: false`), так что новое хранение доступа в checkout его не касается.
  - pnpm 12 официально поддерживается с pnpm/action-setup 6.1.
- [x] **Кэш скачанных наборов в «Данных» один на все наборы.** Исправлено 20 октября 2026 в `.github/workflows/data.yml`:
  - если точного кэша нет, берётся последний с тем же кодом загрузчика, и загрузчик докачивает только изменившиеся наборы;
  - версии, которых нет в `sources.lock.json`, из кэша удаляются, чтобы он не рос;
  - сменился код загрузчика — старый кэш не берётся, всё скачивается заново.
- [x] **Повтор файла в архиве npm ломает кэш набора.** Исправлено 20 октября 2026: путь, который встречается в архиве несколько раз, считается одним файлом, и остаётся последняя копия — как при обычной распаковке (`packages/pipeline/src/sources/tar.ts`).

## Позже

- **Переименования Material Symbols из истории Iconify (268).** Не берём (решение 20 октября 2026). Вернуться, если замер поиска (шаг 12) или MCP покажет промахи по старым именам; тогда — разовая копия списка в репозитории как исключение из ADR-0012.
- **Убрать неверное имя до первой публикации.** После шага 8 исправление имени становится переименованием, и старое имя остаётся алиасом. Если до фазы 2 найдётся ещё одно неверное имя, нужен явный способ убрать его без алиаса — например, список в конфиге набора. Решать при первом таком случае.
- **Смена лицензии в журнале.** Версия набора зависит только от `icons.json`, поэтому смена лицензии выпуском не считается и в журнал не попадает; сейчас её останавливает сборка до подтверждения владельцем (ADR-0017). Решить к фазе 4, нужна ли такая запись в ленте «Что нового».
- **Указание авторства Feather у иконок Lucide (фаза 4).** LICENSE Lucide — это ISC и раздел MIT для иконок, пришедших из Feather; список таких иконок в нём записан старыми именами. На странице иконки (ADR-0041) у них нужно указывать и Feather.
- **Порядок вариантов на сайте (фаза 4).** В `metadata.json` ключи `suffixes` записаны по кодам символов, а не в порядке Thin → Light → Regular → Bold. Сайту нужен свой порядок.
- **Оттенки кожи Fluent Emoji не сгруппированы.** Как у Iconify, `waving-hand-dark` — отдельная иконка без карты вариантов. Для поиска «один документ на базовую иконку» (ADR-0027) и переключателя на сайте их, возможно, стоит группировать. Решить на шаге 12 или в фазе 4.
- **Список известных находок контроля.**
  - «Новые находки» в PR робота — это находки у добавленных, изменённых, вернувшихся и переименованных иконок.
  - Не попадает иконка, у которой изменился исходник автора, а результат остался тем же.
  - Точнее был бы список известных находок, как для четырёх обрезанных Material Symbols.
- **Ежедневная пересборка открытого PR Fluent Emoji.**
  - Пока PR робота открыт, он пересобирается каждый день, а для Fluent это ≈254 МБ скачивания.
  - Если станет мешать — не собирать, когда не изменились ни версия, ни main.
- **PR, закрытый роботом, тоже считается отклонённым.** Робот закрывает свой PR, когда версия уже в main. Если автор потом откатит выпуск и выпустит ту же версию снова, робот её не предложит. Случай редкий.
- **Расписание выключается после 60 дней без активности.** Это правило GitHub для открытых репозиториев. Пока идёт разработка, активность есть; после запуска — следить мониторингом (ADR-0028).
- **`pin` по имени тега.** `pnpm sources pin lucide 1.60.0` сейчас не работает: нужен полный хэш коммита. Для наборов на тегах удобно принимать имя тега.
- **pixelmatch 8.** Версия 8.0.0 (6 октября 2026) считает цвет иначе (OKLab) и лучше работает с прозрачностью. Обновлять, когда версия проживёт хотя бы несколько недель. При обновлении меняются числа отличий, поэтому пороги ADR-0016 нужно перепроверить на всех наборах.

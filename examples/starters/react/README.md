# Iconavo with React

A Vite app with the `Icon` component from `@iconavo-ui/react`: size and color, a label for screen readers, and an icon that changes with state.

[Open in StackBlitz](https://stackblitz.com/github/iconavo/iconavo/tree/main/examples/starters/react?file=src%2FApp.tsx&startScript=dev)

To run it on your computer:

```sh
npm install
npm run dev
```

Documentation: [iconavo.dev/docs](https://iconavo.dev/docs)

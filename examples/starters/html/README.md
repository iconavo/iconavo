# Iconavo without a build step

A plain HTML page with the `<iconavo-icon>` tag. Two lines in `<head>` load it from jsDelivr: no install, no build.

[Open in StackBlitz](https://stackblitz.com/github/iconavo/iconavo/tree/main/examples/starters/html?file=index.html&template=html)

To run it on your computer, open `index.html` in a browser, or serve the folder with any web server.

Documentation: [iconavo.dev/docs](https://iconavo.dev/docs)
